# Photographer Project V3 - Grid

A simple portfolio page designed to showcase architectural projects and images in a grid layout.

## Features

- Image gallery created with CSS Grid
- "Details" effect displayed when hovering over images
- Montserrat font
- Simple navigation and footer sections

## Technologies Used

- HTML
- CSS

## How to Run

After downloading the project, open the `index.html` file in your browser. No additional setup is required.

## Images

The images used in the gallery are sourced from Unsplash.
